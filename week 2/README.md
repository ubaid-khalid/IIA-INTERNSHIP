## 📌 Overview

This project is a collection of interactive demos and exercises created during the second week of the frontend web development internship. It covers the core concepts of JavaScript, from basic variables and data types to advanced DOM manipulation, event handling, and form validation.

The project is structured into daily tasks (`w2d1` to `w2d5`), each focusing on specific JavaScript concepts:

- **Day 1:** Variables, Data Types, Operators, and Introduction to DOM.
- **Day 2:** Conditions (`if/else`, `switch`), Selectors (`querySelector`, `querySelectorAll`), and Event Handling.
- **Day 3:** Loops (`while`, `do-while`, `for`, `forEach`, `map`) and Event Listeners.
- **Day 4:** Functions (Declarations, Expressions, Parameters) and Form Validation.
- **Day 5:** Mini Project combining Conditionals, Loops, DOM Selection, and Testing.
