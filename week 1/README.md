# My React App

A modern, fast, and responsive React application built during the frontend web development training. This project focuses on utilizing modern JavaScript (ES6+) features, robust tooling, and a component-based architecture to deliver a seamless user experience.

## 🚀 Tech Stack

*   **Framework:** [React](https://reactjs.org/)
*   **Build Tool:** [Vite](https://vitejs.dev/) for lightning-fast Hot Module Replacement (HMR) and optimized development builds.
*   **Linting:** [Oxlint](https://oxc.rs/docs/guide/usage/linter.html) configured via `.oxlintrc.json` to ensure code quality, maintain consistency, and catch syntax errors early.
*   **Bundler:** [Rolldown](https://rolldown.rs/) for high-performance JavaScript bundling.
*   **Utilities:** [Nanoid](https://github.com/ai/nanoid) for generating secure, unique, and URL-friendly string IDs.

## ✨ Features

*   **Modern JavaScript:** Leverages ES6+ syntax, including arrow functions, destructuring, spread operators, and array manipulation methods.
*   **High Performance:** Bootstrapped with Vite to provide instant server start and fast compilation.
*   **Code Quality Enforcement:** Strict linting rules to maintain clean, readable, and professional code.
*   **Responsive Architecture:** Structured to be styled seamlessly with semantic HTML5 and modern CSS techniques like CSS Grid and media queries.
